# blog-api

Backend for the Blog Management project. Full setup, API test checklist, troubleshooting,
deployment steps and the viva cheat sheet are in the main README one folder up: `../README.md`.

Quick start:

```bash
npm install
cp .env.example .env     # then fill in DATABASE_URL and JWT_SECRET
npm run dev              # http://localhost:5000  (docs at /docs)
```
